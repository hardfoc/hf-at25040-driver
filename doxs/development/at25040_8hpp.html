Detailed Description

Header-only Microchip AT25010/020/040B SPI EEPROM driver.

SPI Mode 0, 8-bit frames. READ/WRITE use a 9-bit address with A8 in bit 3 of the opcode. Probe is hardware-absent safe: floating MISO (0xFF) and MOSI echo of RDSR (0x05) are treated as absent. Do not clock the part from static constructors — call Probe from an explicit attach / console / HIL path.
