# AT25040 Driver API reference {#mainpage}

The classes, functions and constants of the HardFOC AT25040 driver, generated from the headers.

Start with at25040::Device, the driver, and at25040::SpiInterface, the interface your platform port implements.
Opcodes, status bits and the array geometry are constants in the at25040 namespace (at25040_registers.hpp);
results are at25040::Status.

The guides, with examples that compile, are on the documentation site: <a href="../">AT25040 Driver
documentation</a>.
